# One-line installable action

## Want
Any repo adds the intent gate with one `uses: SM260845/intent-first@v1` step.
The action takes `base-ref` / `head-ref` inputs and a `strict-touches` switch
(the `--touches=warn|fail` mode from #3), annotates each failure on the file
that caused it, and writes a job summary that says how to fix it.

## Not
No new dependencies: Python 3, git and bash only. No rule changes beyond the
opt-in strict touches mode. No rename of the required checks `intent-check`
and `selftest`. The existing `run-checks` and `require-proof` inputs keep working.

## Done when
- Strict and default touches modes behave as specified, alongside every existing rule
  check: `python3 scripts/test_intent_check.py`
- action.yml carries the Marketplace metadata (name, description, branding)
  check: `grep -q "^name: Intent-First Gate" action.yml && grep -q "^branding:" action.yml`
- This PR passes through `uses: ./`
- A consumer repo on `@v1` passes a valid intent and fails the junk intent `hi`
